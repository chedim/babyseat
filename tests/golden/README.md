# Frozen recordings of the last Python seat

These files were recorded from the released Python seat (tag `v0.7.53`; the seat itself is preserved at tag `python-seat-last`) and are the
oracle the Rust seat's tests compare against (`native/tests/{boot_routes,session,legacy_routes}_1143.rs`). They are frozen: the scripts that
recorded them are gone, nothing regenerates them, and a change to one is a decision to depart from the released answer.
The per-folder READMEs name the recording scripts as they were (`git show python-seat-last:scripts/golden_boot.py`).
