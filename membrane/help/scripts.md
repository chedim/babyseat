Entity behaviour is a `.c1f` pack now: help('packs'). The old Python `*_script` properties (getter_script, tick_script, watch_script, ...) are retired: at boot the seat's upgrade turns the ones it recognises into pack kinds (the entity gains a `cls:<kind>` parent) and marks the rest `script_port.pending` for translation. Do not write new `*_script` properties; a getter replaces getter_script, a getter on `clock` replaces tick_script, a getter reading stat(path) / read(path) replaces a file watch_script, and a write to an adapter (chat:<person>.say, membrane::llm.call, Command.run) replaces a script's side effects.
