Cliffhanger is membrane as an OOP language: entities are objects, ISA parents are classes, METHODS are commands attached to a class or object, a CALL is an event on an object. Define once: exec(action='define', on='ha light', method='turn_on', command='. ~/.config/membrane/hass.env; curl -s -X POST -H "Authorization: Bearer $HASS_TOKEN" -d "{\"entity_id\": \"{{self.entity_id}}\"}" $HASS_URL/api/services/light/turn_on'). Call it on any member: exec(action='call', object='ha:light.port_strip', method='turn_on'). {{self.<prop>}} fills from the object (its own values over its classes'); other {{params}} come from args -- ONLY {{name}} binds ({name}, $name, $1 do not): an arg the command never names is refused, a positional list args=[a, b] binds to the {{params}} in order, and args.timeout (seconds) only ever shortens the run. INSPECT (runs nothing): exec(action='inspect', object=..., method=..., args=...) shows where the call resolves (via, the resolution order, who defines it along it), the stored command, params and steps, and with args the exact command it WOULD run or the refusal it WOULD give -- look before you redefine a broken method. Dispatch: the object's own method, then its classes (ISA order), then global methods -- the same name on another class is its own implementation. The receipt lands on the object. Compose methods with parents (help('exec')). A missing or empty value BLOCKS the call (nothing runs); outcomes: ok | blocked | error | timeout | partial. The receipt shows which implementation answered (via), the resolution order and the exact command that ran. Mark reads read_only=true. GUARDS: define(..., guard="result = {'ok': state['self'].get('reachable') == 'yes'}") runs first; false = blocked, nothing runs. COMPOSITES: define(..., steps=[{'name': 'soc', 'call': 'read', 'object': 'seat:battery'}, {'name': 'lights', 'call': 'turn_off', 'object': 'self'}]) -- steps run in order, stop on failure (partial if earlier ones ran), nest at most 3 deep; {{steps.soc.state.soc}} reads a step's captured result (JSON output becomes .state), {{entities.<spec>.<field>}} reads an entity now. Every node is an entity you can read. FAN-OUT: exec(action='each', over='ha light', method='status', dry_run=true) lists who would be hit; without dry_run it runs on every member (cap max=20, raise it explicitly; ceiling 150), on_fail='abort' (default) | 'continue', one summary receipt; as a step: {'name': 'all', 'each': 'ha light', 'call': 'turn_off'}. INTERFACES: exec(action='define', on='remote_executor', method='exec(code, timeout)', abstract=true) declares a required method (no command) and makes its owner an interface; an entity that inherits it must implement each one (own or a class between) -- until then the call is blocked with what is missing, and inherit says what it owes. remote_executor (exec(code, timeout)) is the first: an environment that runs code; give each implementation lang / env / trust properties.
