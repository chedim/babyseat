Cliffhanger is membrane as an OOP language: entities are objects, ISA parents are classes, and BEHAVIOUR IS A PACK -- getters that keep a value true and setters that react to a write (help('packs')). Act by WRITING to an entity: a setter reacts, or a driver verb does the effect (entity(action='write', spec=..., prop=..., value=...)).

ENTITY METHODS ARE RETIRED (#1101): there is no define / call / each / inspect any more. At every start the seat translates each old method whose command binds mechanically into a `Command:<name>` entity (the name is the method's "owner.method" with '.', ':' and spaces as '_'; `cmd` is the command, `read_only` kept, `from_method` its old id). Its {{param}}s became the positional words "$1", "$2", ... in the order they first appear (`params` lists them). Run one by writing Command:<name>.run = {id: '<a request id>', args: [<the values in that order>]}; the receipt lands on the entity (run_result {status, rc, head, stdout, stderr}, run_rc). A Command that already exists is never rewritten. The methods that did NOT translate (steps, a guard, abstract, {{self.x}} or {{parent}} placeholders, more than four placeholders, a placeholder inside single quotes) are listed on the entity `Methods:review`, `untranslated` = [{eid, name, why}] -- rewrite each as a pack or a Command by hand.

A call straight at the executor (tool:executor, remote_executor, an implementation's exec) stays refused. Mark reads with read_only on the Command. See help('stdlib') for Command, File and the read(path) getters, and help('packs') for the language.
