PACKS: an entity's behaviour is a `.c1f` pack -- the field engine's own language, run natively, no Python. exec(action='load', name='<pack>', c1f='<the whole text>') (the `pack` tool for Claude) loads it at once and answers with its load error (a broken pack is refused; the last good one keeps running); exec(action='show', name=...) shows it with its error, exec(action='packs') lists them. It is the entity membrane::pack:<name> (class Pack; any entity holding `c1f` is a pack). A running getter's error lands on its entity as `refused` (shown, never hidden). Shipped packs (banner, mcp, store, fs, proc, ported, goalgraph) are the release's: extend one from your own pack with `IMPORT <it> 1` and your own class.

A pack starts `PACK <name> <version>` (then `IMPORT <pack> <version>` lines) and declares fields on classes:
- getter: `Battery.low getter: this.soc < 20` -- a cached value, recalculated when anything it read changes. Its own name reads its previous value. A getter that reads `clock` recalculates on every tick (about 1 s): that is how time reaches a field -- no tick scripts.
- arms: `Light.word getter WHEN this.level > 0: 'on'` then `Light.word getter: 'off'` (the arm without WHEN is the default, last); block form `X.f getter:` then indented `WHEN c: e` / `ELSE WHEN c: e` / `ELSE: e`. `X.f getter: this.f` as the default keeps the value.
- setter: `Light.level on-setter word:` then indented `WHEN c:` / `ELSE WHEN c:` / `ELSE:` / `ALWAYS:` branches of writes (`this.word = 'on'`, `this.goal.replan = ...`, `('DomNode:x:' + this.eid).text = ...`; writing to an id that does not exist yet creates it), and `FOR t IN <list>:` blocks. It runs after a write to its field; the first true branch runs, and only it.
- expressions: Python-like (`a if c else b`, `[f(x) for x in xs]`, `FOR x IN xs: e`), `this`, `prop(x, name)` (a dict key or another entity's field, by id), `this.eid`. Caps: 400 characters and 64 nodes per arm (string literals excluded): split long logic into small named getters -- each is a field you can read.
- built-ins: text (lower, strip, startswith, lines, words, join, head, clip, before, after, str, json), lists (concat, sort_by, fit, distinct, group_by, pluck; `+` on lists adds vectors), time (localtime, ago, epoch), entities (instances(cls)), reads (sql(query, args...) and jsonl(name) on the seat's store -- see help('store'); read(path), listdir(path), stat(path)).
- reads are getter-only and never block: a getter reads None until the answer lands, then recalculates. A setter that needs it reads the getter's field.
- effects are WRITES, never getters: `File.write`, `Command.run`, `McpTool...call:run`, `membrane::llm.call`, `chat:<person>.say` -- from a setter, or by you with entity(action='write', spec, prop, value) -- each leaves a receipt on its entity (`<verb>_result`, `<verb>_rc`). Reach is the seat's OS user.

A class belongs to the first pack that declares on it; another pack that adds fields to it must `IMPORT` that pack (the load error says which).

Which entities a pack's fields apply to: an entity of the class, or one with that class among its ISA parents (`parents`). entity(action='add'/'edit') accepts any class a loaded pack declares. Shipped packs (read them as examples): banner, mcp, store, fs, proc, ported, goalgraph.

`*_script` properties (Python) are retired: the seat's upgrade moves them into packs at boot; never write a new one. Reference: docs/cliffhanger-fields.md (sections 10-11).
